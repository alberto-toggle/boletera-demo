# Fotografías de las propuestas

Copias locales descargadas de `images.unsplash.com` para los eventos ficticios.
Las URLs originales se solicitaron con `auto=format&fit=crop&w=1800&q=85`.
Las vistas sirven estos archivos con `next/image`; no consultan Unsplash en tiempo
de ejecución. Las fotografías son ilustrativas, no imágenes de sedes confirmadas.
