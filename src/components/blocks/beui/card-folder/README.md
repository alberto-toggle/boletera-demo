# Card Folder — BE UI

- Autor: Saurabh <saurabh10102@gmail.com>.
- Origen: https://beui.dev/components/blocks/card-folder
- Registro: https://beui.dev/r/card-folder.json (`@beui/card-folder`).
- Descargado el 5 de octubre de 2026 mediante `npx shadcn add @beui/card-folder --view`.
- Vista: `/playground/beui/card-folder`.

Se conserva el componente y sus auxiliares DigitSwap y ease en esta carpeta.
Se adaptaron los imports a `framer-motion` ya instalado (misma API Motion),
se reutiliza `@/lib/utils` sin sobrescribirlo y se tradujeron etiquetas a español.
Conserva controles por teclado, estado controlado/no controlado y movimiento reducido.
El registro no incluye un campo de licencia ni cabecera de licencia adicional.

La demo utiliza únicamente datos ficticios y no persiste información.
Antes de reutilizarlo para métodos guardados, adaptar la presentación a marca,
últimos cuatro dígitos y referencia del proveedor de pagos; el revelado de CVV
es parte del ejemplo del proveedor, no una función de la cuenta de comprador.
