# Cards Slider

Origen: registro shadcn `@uitripled/cards-slider-shadcnui` (UI TripleD).

Se reutilizan Avatar, Badge, Card y Framer Motion existentes. Sin dependencias nuevas ni sobrescrituras.

Adaptaciones: límites de arrastre recalculados con ResizeObserver, posición ajustada al redimensionar, controles siempre visibles y deshabilitados en los extremos, teclado limitado al carrusel, anchura de tarjeta según el contenedor, estructura compatible con Card base-nova y movimiento reducido. Se desactiva el arrastre nativo de imágenes para permitir el gesto de Framer Motion. Se conservan las cinco tarjetas e imágenes externas originales. View Details está desactivado porque no hay vistas de artículos.

Vista: `/playground/uitripled/cards-slider-shadcnui`. Categoría: Galerías.
