# Theater Ticket

Origen: registro shadcn `@uitripled/theater-ticket-shadcnui` (UI TripleD).

Se reutilizan Badge y Framer Motion existentes. Sin nuevas dependencias ni sobrescritura de primitivas.

Adaptaciones: distribución vertical hasta pantallas grandes, ancho y tipografía adaptables al playground, espacio fijo para el talón y respeto de movimiento reducido. Se conservan los datos y la textura externa de transparenttextures.com del original. Código de barras decorativo, sin compra ni validación de entradas.

Vista: `/playground/uitripled/theater-ticket-shadcnui`. Categoría: Boletos.
