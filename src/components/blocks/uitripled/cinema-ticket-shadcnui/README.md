# Cinema Ticket

Origen: registro shadcn `@uitripled/cinema-ticket-shadcnui` (UI TripleD).

Se reutilizan Badge y Framer Motion existentes, sin nuevas dependencias ni sobrescritura de primitivas.

Adaptaciones: espaciado y tipografía para pantallas pequeñas, metadatos con salto de línea, iconos sin contracción y respeto de movimiento reducido. Se conservan la imagen externa de Unsplash y datos de ejemplo del original, incluido el año 2025. El QR es decorativo; no se generan entradas válidas.

Vista: `/playground/uitripled/cinema-ticket-shadcnui`. Categoría: Boletos.
