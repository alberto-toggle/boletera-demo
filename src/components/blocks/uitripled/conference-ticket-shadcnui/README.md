# Conference Ticket

Origen: registro shadcn `@uitripled/conference-ticket-shadcnui` (UI TripleD).

Instalado reutilizando Avatar, Badge y Framer Motion existentes. Sin dependencias adicionales ni modificaciones a primitivas compartidas.

Adaptaciones: estilos de brillo en CSS Module (el registro referenciaba una animación no definida), perspectiva explícita, distribución vertical hasta pantallas grandes, tamaños y espaciado adaptables, encabezado h2 y respeto de movimiento reducido. Datos originales de ejemplo, incluido el año 2025. El QR es un icono decorativo, no un boleto válido.

Vista: `/playground/uitripled/conference-ticket-shadcnui`. Categoría: Boletos. El árbol mantiene su orden alfabético y estado colapsado inicial.
