# Glass Wallet Card

Origen: registro shadcn `@uitripled/glass-wallet-card-shadcnui` (UI TripleD).

Reutiliza Card, Badge, Button y Framer Motion existentes. No se añaden dependencias ni se sobrescriben primitivas.

Adaptaciones: espaciado compatible con Card base-nova, altura flexible y saltos de línea para pantallas pequeñas, movimiento reducido, icono de tendencia bajista cuando trendUp=false y saldo sin prefijo dólar incompatible con ETH. Acciones visibles al pasar el cursor o mediante botón accesible para teclado y móvil. Send/Receive desactivados, con aviso visible; no existe conexión a una billetera ni transferencias.

Vista: `/playground/uitripled/glass-wallet-card-shadcnui`. Categoría: Checkout y pagos. Datos ficticios del original.
