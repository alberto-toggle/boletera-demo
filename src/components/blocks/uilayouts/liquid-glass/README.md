# Liquid Glass · UI Layouts

Descargado con `npx uilayouts@latest add liquid-glass` (CLI 1.0.3).
Origen: https://github.com/ui-layouts/uilayouts
Licencia original conservada en `LICENSE`.

`liquid-glass.tsx` conserva las capas de distorsión SVG, desenfoque, reflejos,
brillo y movimiento del componente descargado. Adaptaciones locales: TypeScript
estricto sin `ts-nocheck`, ID de filtro único por instancia, capas decorativas sin
captura de puntero, contenido por encima de las capas, expansión por teclado y
respeto por movimiento reducido. `demo.tsx` contiene únicamente el ejemplo y sus
controles. El arrastre es elástico y regresa a su posición inicial.

Ruta: `/playground/uilayouts/liquid-glass`.
No se aplica a las propuestas públicas ni al panel administrativo.
