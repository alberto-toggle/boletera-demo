# Modern & Stunning Sign In

- Autor: preetsuthar17 / 21st.dev.
- Origen: https://21st.dev/@preetsuthar17/components/modern-stunning-sign-in
- Registro: https://21st.dev/r/preetsuthar17/modern-stunning-sign-in
- Código recuperado mediante MCP de 21st, demo 2060.
- El registro consultado no incluye una licencia específica.

Se conserva el diseño oscuro, la marca HextaUI, los textos y los recursos del
ejemplo original. Adaptaciones: formulario semántico con envío por teclado,
etiquetas y mensajes accesibles, foco visible, imágenes Next sin optimización
remota y callbacks tipados separados de la simulación del playground.
Las acciones muestran avisos locales; no hay autenticación real, persistencia,
envío de datos ni registro de contraseñas. No se añaden dependencias ni se
sobrescriben primitivas compartidas.
