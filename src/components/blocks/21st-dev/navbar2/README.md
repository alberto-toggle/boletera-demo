# Mega Menu Navbar (navbar2)

Origen: https://21st.dev/@anelkabag/components/navbar2
Autor: anelkabag. Recuperado mediante el MCP de 21st.dev (demo 31723).
Registro: https://21st.dev/r/anelkabag/navbar2

Vista: /playground/21st-dev/navbar2. Categoría: Navegación.

Se conserva el diseño claro y el contenido de muestra del autor.
Adaptaciones: framer-motion existente en lugar de motion/react, react-icons
para los iconos sociales, fixtures en navbar2-data.ts, imágenes con next/image
sin optimización remota y enlaces locales a la vista previa para evitar 404.
El selector de idioma es ilustrativo: cambia la selección, no traduce el contenido.
Se añade cierre con Escape, foco visible, estados aria-expanded y movimiento
reducido. El breakpoint depende del ancho disponible del bloque para convivir
con el sidebar. Se retira el recorte exterior que ocultaba el desplegable de idiomas.

No se sustituyen primitivas compartidas ni se añaden dependencias Radix.
La respuesta del MCP no incluye una licencia específica; conservar la atribución
y comprobar los términos del proveedor antes de redistribuir el bloque.
