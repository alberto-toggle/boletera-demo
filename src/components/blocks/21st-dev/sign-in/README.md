# Sign In

- Autor: jahed / 21st.dev.
- Origen: https://21st.dev/@jahed/components/sign-in
- Registro: https://21st.dev/r/jahed/sign-in
- Componente y demo obtenidos mediante MCP de 21st, demo 3197.
- El registro consultado no declara una licencia específica.

Se conservan la composición, las imágenes, los testimonios y los textos originales.
Adaptaciones: límite cliente, rutas locales, dimensiones relativas al playground,
breakpoints de contenedor, etiquetas y foco accesibles, imágenes de Next sin
optimización remota y CSS de animaciones aislado con movimiento reducido.
El código recibido nombraba clases de animación sin aportar sus definiciones;
se agregaron transiciones de entrada locales para esas clases.

Las acciones muestran avisos de simulación. No hay autenticación, persistencia,
envío de credenciales ni registro de contraseñas en consola. No se instalaron
dependencias ni se sobrescribieron primitivas compartidas.
