# Scroll Expansion Hero

Autor: arunachalam.
Origen: https://21st.dev/@arunachalam/components/scroll-expansion-hero
Registro: https://21st.dev/r/arunachalam/scroll-expansion-hero
Recuperado mediante el MCP de 21st.dev (demo 1932).

Vista: /playground/21st-dev/scroll-expansion-hero. Categoría: Heroes.

Se conserva la expansión del medio, el fondo que desaparece y los títulos que
se separan lateralmente, con los datos y recursos originales de video e imagen.
El ejemplo permite cambiar el tipo de medio y la mezcla de texto.

Adaptaciones: scroll nativo en un panel enfocable, sin interceptar eventos
globales ni cambiar el scroll de la página; dimensiones relativas al contenedor;
datos tipados separados; controles de video para pausar; imágenes remotas sin
optimización. Con movimiento reducido se muestra el medio expandido sin
reproducción automática. Cambiar de medio reinicia la vista mediante su key.
Reutiliza framer-motion y Button Base UI; no agrega dependencias ni sobrescribe
primitivas.
