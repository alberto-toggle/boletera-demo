# Scroll Gallery

Autor: soralabs.
Origen: https://21st.dev/@soralabs/components/scroll-gallery
Registro: https://21st.dev/r/soralabs/scroll-gallery

Código y demo recuperados mediante el MCP de 21st.dev; auxiliar recuperado
del registro original. Se conserva el efecto de máscaras por franjas, el
intercambio de títulos y las cuatro imágenes del autor.

Vista: /playground/21st-dev/scroll-gallery. Categoría: Galerías.

Dependencias: gsap (existente) y @gsap/react. Sin primitivas sobrescritas.
Datos del ejemplo separados de la presentación. La vista utiliza el modo
embedded del autor y un contenedor enfocable con scroll propio. Se ajustaron
anchos y tipografía al contenedor, se usa next/image y se ocultan los enlaces
ficticios del ejemplo. Con movimiento reducido se muestran las imágenes
en una lista sin animaciones. La limpieza cancela los tweens de títulos
y reconstruye el efecto al cambiar sus dependencias.
