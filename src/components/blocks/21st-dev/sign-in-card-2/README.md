# Sign In Card

- Autor: jatin-yadav05 / 21st.dev.
- Origen: https://21st.dev/@jatin-yadav05/components/sign-in-card-2
- Registro: https://21st.dev/r/jatin-yadav05/sign-in-card-2
- Código original recuperado mediante MCP de 21st, demo 2026.
- El registro consultado no incluye una licencia específica.

Se conservan la tarjeta, las luces, la inclinación y los textos originales.
Se reutiliza Input de Base UI del proyecto y las dependencias existentes
framer-motion y lucide-react. Adaptaciones: tipado estricto, dimensiones del
playground, etiquetas, foco y botones accesibles, movimiento reducido y
limpieza del temporizador al desmontar.

Los callbacks separan la presentación de los avisos de demo. El acceso simulado
dura dos segundos; no se guardan ni envían credenciales. Recuperación, registro y
Google muestran avisos locales en lugar de navegar a rutas inexistentes.
No se añaden dependencias ni se sobrescriben primitivas compartidas.
