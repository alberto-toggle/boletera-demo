# Hero Gallery Scroll Animation

Autor: youcefbnm.
Origen: https://21st.dev/@youcefbnm/components/hero-gallery-scroll-animation
Registro: https://21st.dev/r/youcefbnm/hero-gallery-scroll-animation
Recuperado mediante MCP de 21st.dev, demo 1849.

Vista: /playground/21st-dev/hero-gallery-scroll-animation. Categoría: Heroes.

Incluye las variantes de cinco, cuatro y tres imágenes (oscura), sus recursos,
textos y composición bento. La galería se expande y el texto se desvanece.

Adaptaciones: framer-motion existente; contexto con contenedor de scroll local;
texto absoluto dentro del panel sticky en lugar de fixed sobre toda la página;
consultas de contenedor; next/image; movimiento reducido; controles invisibles
inert; botones del hero avanzan la demo. Datos separados, sin dependencias nuevas
ni primitivas sobrescritas. Cada cambio de variante reinicia el panel.
