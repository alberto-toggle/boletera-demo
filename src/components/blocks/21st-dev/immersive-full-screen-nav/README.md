Se conserva la demo Northline del autor con sus imágenes, textos y animaciones GSAP.

Adaptaciones para playground:
- Posicionamiento absoluto dentro de una vista previa aislada de 760px de alto;
  unidades y breakpoints relativos a su contenedor. No cubre el sidebar.
- Sin modificación del overflow del body; el panel tiene desplazamiento propio.
- Menú cerrado inerte para teclado y lectores de pantalla.
- Escape, contención/restauración del foco y cierre al seleccionar enlaces.
- Limpieza de animaciones al desmontar; soporte de movimiento reducido del original.
- Imágenes mediante next/image sin optimización remota; enlaces locales de muestra.

Dependencia añadida: gsap. No cambia las primitivas Base UI.
