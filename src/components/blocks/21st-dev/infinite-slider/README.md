# Infinite Slider

Autor: ibelick (Motion Primitives).
Origen: https://21st.dev/@ibelick/components/infinite-slider
Registro: https://21st.dev/r/ibelick/infinite-slider
Código y demo recuperados mediante el MCP de 21st.dev, demo 1247.

Vista: /playground/21st-dev/infinite-slider. Categoría: Galerías.

Se conservan los seis logotipos, fondo blanco, separación de 24px y dirección
inversa del ejemplo. El componente admite orientación, duración y duración al
pasar el puntero.

Adaptaciones: datos separados; next/image sin optimización remota; medición del
primer grupo; duración proporcional al recorrido restante; pausa y reanudación;
pausa al recibir foco; copia decorativa inert y aria-hidden; movimiento reducido
con contenido estático y desplazable. Cada efecto cancela su animación.

Dependencias: framer-motion existente y react-use-measure. Sin primitivas
sobrescritas.
