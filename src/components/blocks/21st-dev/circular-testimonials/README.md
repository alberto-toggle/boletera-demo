Los testimonios, nombres y restaurante del ejemplo son ficticios y se usan
únicamente para demostrar el componente; no representan opiniones de clientes.
El registro recuperado no incluye una licencia específica.

Se conservan ambas variantes del ejemplo original. Adaptaciones: CSS aislado,
dimensiones relativas al contenedor, imágenes Next sin optimización remota,
teclado limitado a cada carrusel, movimiento reducido y guardas para listas vacías.
La reproducción automática es opcional y está desactivada en esta vista; incluye
control de pausa cuando se activa. Se reutilizan framer-motion y react-icons ya
instalados. No se sobrescriben primitivas.
