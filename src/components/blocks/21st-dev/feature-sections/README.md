# Feature Sections

Origen: 21st.dev, confirmado por el usuario. Integrado desde el código pegado; autor específico no indicado.

Se conservaron las dos variantes del archivo: `feature-sections.tsx` (tres tarjetas ilustradas) y `feature-sections-image-list.tsx` (imagen y lista con iconos). Ambas se muestran en una sola vista. Son componentes estáticos sin dependencias adicionales.

Adaptaciones: retirar imports no usados y la regla global `* { font-family: Poppins }` con importación remota de fuentes; heredar la tipografía del proyecto. Colores compatibles con tema claro/oscuro, imágenes adaptables y de carga diferida, estructura responsive de la segunda variante, encabezado h2, iconos decorativos y movimiento reducido en hover. Los textos originales se mantienen como contenido ilustrativo.

Vista: `/playground/21st-dev/feature-sections`. Categoría: Secciones de características. Código y auxiliares junto al bloque, sin sobrescribir primitivas ni estilos globales.
