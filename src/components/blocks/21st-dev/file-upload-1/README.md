# File Upload — Imagen y carpeta

Autor: anubra266.
Origen: https://21st.dev/@anubra266/components/file-upload-1
Registro: https://21st.dev/r/anubra266/file-upload-1
Código y demo recuperados mediante MCP de 21st.dev, demo 6341.

Vista: /playground/21st-dev/file-upload-1. Categoría: Carga de archivos.

Se incluyen el selector básico de imagen y la demo de directorio, con sus
miniaturas, listado, tamaños y acciones para eliminar o vaciar la selección.
Selección local, sin backend ni transferencia de archivos. La compatibilidad
con directorios depende del navegador.

Dependencia: @ark-ui/react/file-upload, aislada en estos bloques. No sustituye
las primitivas Base UI ni agrega variantes compartidas de Button.
Adaptaciones: textos y locale en español, acciones con etiquetas accesibles,
botón explícito para abrir el selector de carpeta y movimiento reducido.
