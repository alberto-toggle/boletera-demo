# Scroll Trigger Animations

Autor: youcefbnm.
Origen: https://21st.dev/@youcefbnm/components/scroll-trigger-animations
Registro: https://21st.dev/r/youcefbnm/scroll-trigger-animations
Recuperado mediante MCP de 21st.dev, demo 3531.

Vista: /playground/21st-dev/scroll-trigger-animations.
Categoría: Animaciones.

Incluye los contenedores originales de escala, desplazamiento, recorte horizontal,
vertical y combinado, y radio de borde. La vista usa la imagen del ejemplo del
autor y su escala de 0.4 a 1, con desplazamiento adaptado al panel sticky.

Adaptaciones: framer-motion existente en lugar de motion/react; scroll nativo
en lugar del hook global Lenis; soporte opcional de contenedor y offsets;
rangos numéricos tipados; movimiento reducido; next/image sin optimización remota.
No instala dependencias ni sobrescribe primitivas compartidas.
