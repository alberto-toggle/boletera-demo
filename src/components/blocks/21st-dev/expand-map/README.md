# Expand Map

Autor: jatin-yadav05.
Origen: https://21st.dev/@jatin-yadav05/components/expand-map
Registro: https://21st.dev/r/jatin-yadav05/expand-map
Recuperado mediante MCP de 21st.dev, demo 9635.

Vista: /playground/21st-dev/expand-map. Categoría: Mapas.

Conserva la tarjeta, inclinación, expansión, calles y edificios SVG del autor.
El mapa es ilustrativo: no usa proveedor cartográfico ni geolocalización.
La insignia Live se cambia a Demo para no representar información en vivo.

Adaptaciones: activación por Enter/Espacio, Escape para contraer, foco visible,
aria-expanded, ancho limitado al contenedor, movimiento reducido, identificador
SVG único y colores compatibles con los tokens actuales de Tailwind/shadcn.
Reutiliza framer-motion; no agrega dependencias ni sobrescribe primitivas.
