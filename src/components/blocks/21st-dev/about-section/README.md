# About Section

Autor: uilayout.contact.
Origen: https://21st.dev/@uilayout.contact/components/about-section
Registro: https://21st.dev/r/uilayout.contact/about-section
Recuperado del registro autenticado de 21st.dev.

Vista: /playground/21st-dev/about-section. Categoría: Secciones de presentación.

Conserva composición, imagen recortada, estadísticas, textos y enlaces del autor.
El CTA muestra un estado de demostración local. Las cifras son ilustrativas.

Auxiliares:
- TimelineContent: implementación local compatible con las variantes del bloque,
  porque el registro uilayout.contact/timeline-animation devolvió 404.
- VerticalCutReveal: danielpetho, https://21st.dev/@danielpetho/components/vertical-cut-reveal,
  recuperado mediante MCP (demo 884), con limpieza y dependencias de efectos
  corregidas, movimiento reducido y orden pseudoaleatorio determinista.

Adaptaciones: consultas de contenedor; next/image sin optimización para iconos;
identificador único de clipPath; semántica de encabezados; movimiento reducido.
Reutiliza framer-motion y lucide-react. No instala dependencias ni sobrescribe
primitivas compartidas.
