# Product Card Event

Origen: https://www.shadcn.io/blocks/product-card-event
Registro: https://www.shadcn.io/r/product-card-event.json (requiere acceso autorizado).
Proveedor: shadcn.io. Importado el 30 de septiembre de 2026.

Vista: `/playground/shadcn-io/product-card-event`.

Adaptaciones:

- Imports `~/` convertidos a `@/` y ubicación separada por proveedor.
- Primitivas oficiales compartidas: Badge, Button, Card, Label y RadioGroup,
  generadas con el preset Base UI Nova del proyecto.
- Nombre del componente descriptivo, IDs únicos, etiquetas para botones de
  cantidad y foco visible en las opciones de boleto.
- Imagen servida con Next Image sin optimización; conserva la URL externa de
  Unsplash del ejemplo y requiere conexión a internet.
- Ajustes locales del espaciado de Card para integrar la imagen con Nova.
- Encabezado subordinado al título de la página; datos originales en inglés.
- Compra deshabilitada y señalada como vista previa. Selección, cantidad (1 a 8),
  disponibilidad y cálculo del total conservan el comportamiento del ejemplo.

No se guardan credenciales ni tokens de descarga en el repositorio.
