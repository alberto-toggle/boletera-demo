# App Finance 1

Origen: registro shadcn `@paceui/app-finance-1` (Pace UI).

A visual commodities portfolio tracker showcasing gold, silver, and crude oil allocations with an integrated segmented bar chart and detailed item metrics.

Descargado mediante `shadcn view` para respetar los destinos del playground sin sobrescribir primitivas. Dependencias compartidas instaladas con estilo Base UI `base-nova`. Código cliente, tipos estrictos y datos de ejemplo deterministas cuando corresponde. No se conecta a servicios reales.
