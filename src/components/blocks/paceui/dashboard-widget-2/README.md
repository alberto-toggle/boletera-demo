# Dashboard Widget 2

Origen: registro shadcn `@paceui/dashboard-widget-2` (Pace UI).

Se instaló el bloque reutilizando Card y Badge de Base UI. Sin nuevas dependencias ni sobrescritura de primitivas.

Adaptaciones: directiva cliente, ancho adaptable y desplazamiento horizontal del mapa en pantallas pequeñas, etiquetas de asientos y precios, estado seleccionado, asientos reservados con aria-disabled (enfocables para consultar detalles pero no seleccionables), foco visible y detalles con teclado. Total anunciado al cambiar la selección. Respeta movimiento reducido. Datos originales de ejemplo, sin reservas ni pagos.

Vista: `/playground/paceui/dashboard-widget-2`. Categoría: Selectores de asientos.
