# Filmstrip Gallery

Origen: https://www.shadcn-ui-blocks.com/r/marketing-gallery-filmstrip-gallery.json

Se instaló únicamente el bloque, reutilizando Button de Base UI sin añadir Radix ni sobrescribir primitivas.

Se conserva la tira horizontal de nueve fotografías del código original (sin vista ampliada adicional). Adaptaciones: directiva cliente, cálculo de límites al desplazar y redimensionar, controles deshabilitados en los extremos conservando el foco, navegación por teclado local, dimensiones y carga diferida de imágenes y respeto de movimiento reducido. El desplazamiento táctil usa el scroll nativo. Imágenes externas de Unsplash.

Vista: `/playground/shadcn-ui-blocks/marketing-gallery-filmstrip-gallery`. Categoría: Galerías, orden alfabético compartido con el resto del árbol.
