# Carousel Gallery

Origen: https://www.shadcn-ui-blocks.com/r/marketing-gallery-carousel-gallery.json

Instalado únicamente el bloque, reutilizando Button de Base UI y las dependencias existentes. No se importó el botón Radix del registro.

Adaptaciones: directiva cliente, imágenes constantes fuera del render, teclado limitado a la galería, etiquetas accesibles, miniatura seleccionada, gesto horizontal táctil, pausa manual y por interacción, pausa al pasar el cursor y respeto de movimiento reducido. Temporizador con limpieza al desmontar. Imágenes externas de Unsplash del original.

Vista: `/playground/shadcn-ui-blocks/marketing-gallery-carousel-gallery`. Categoría del árbol: Galerías.
