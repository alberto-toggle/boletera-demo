# Event Registration Countdown

Origen: https://www.shadcn-ui-blocks.com/r/marketing-hero-forms-event-registration-countdown.json

Se instaló únicamente el bloque del registro. Se excluyeron sus primitivas Radix y dependencias repetidas; Select se instaló desde shadcn con la configuración base-nova del proyecto.

Adaptaciones: directiva cliente; fecha de ejemplo fija (30 de octubre de 2027, UTC) para evitar diferencias de hidratación; cuenta regresiva con limpieza del temporizador y límite en cero; selección controlada con etiquetas Base UI y total actualizado; identificadores únicos; imagen decorativa; diseño adaptable al área del playground. Envío de formulario desactivado y prevenido, sin integración externa de registro. Descuento de ejemplo de $50 para todos los pases.
